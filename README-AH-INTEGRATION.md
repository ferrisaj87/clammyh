# Clammy Token - Chrome Extension

Silently captures your HorizonXI session token in the background so that `/clammyh reloadah` works without ever opening a browser window or asking you to paste anything.

---

## How it works

1. You log in to [horizonxi.com](https://horizonxi.com) normally in Chrome.
2. The extension intercepts the `Authorization: Bearer` token that the site sends to its API.
3. It writes that token to a file on disk (`horizon_bearer.txt`) via a small Node.js helper (the **native host**).
4. When you type `/clammyh reloadah` in FFXI, Clammy reads that file - no browser pop-up, no manual copy/paste.

The token is valid for ~3 days. After it expires Clammy will ask you to re-capture (just visit horizonxi.com while logged in and the extension will grab a fresh one automatically).

---

## Requirements

- **Google Chrome** (any recent version)
- **Node.js LTS** - [nodejs.org](https://nodejs.org)

---

## Installation

### Step 1 - Load the extension in Chrome

1. Open Chrome and go to `chrome://extensions`
2. Enable **Developer mode** (toggle, top-right)
3. Click **Load unpacked**
4. Browse to this folder:
   ```
   Game\addons\clammyhorizon\chrome-extension
   ```
5. The extension loads. You'll see a small **C** icon in your toolbar.

### Step 2 - Copy your Extension ID

On the `chrome://extensions` page, find **Clammy HorizonXI Token** and copy the long ID string underneath the name. It looks like:

```
fpocpojdcegoneblngjomepdkkdhfkic
```

You'll need this in the next step.

### Step 3 - Install the native messaging host

The native host lets the extension write files to your disk.

1. Open File Explorer and navigate to:
   ```
   Game\addons\clammyhorizon\chrome-extension\native-host\
   ```
2. Double-click **`install.bat`**
3. When prompted, paste the Extension ID you copied in Step 2
4. The script:
   - Creates a `.bat` launcher for the Node.js host
   - Writes the native messaging manifest (`com.clammy.tokenhost.json`)
   - Registers it in the Windows Registry under your user account (`HKCU`)

> **Note:** `install.bat` runs `install.ps1` with `-ExecutionPolicy Bypass`. It only modifies your user registry, not system-wide.

### Step 4 - Verify it's working

1. Go to [horizonxi.com](https://horizonxi.com) and log in if you aren't already
2. Navigate to any item page (e.g. `/items/crab_shell`)
3. Click the **C** icon in the Chrome toolbar
4. The popup should show:
   - ✅ **Token valid** - expiry date
   - ✅ **Native host** - OK
   - Your HorizonXI username

If it shows a token but the native host says **not connected**, re-run `install.bat` (make sure Node.js is installed first).

## Using it with Clammy

Once installed, `/clammyh reloadah` will automatically use the saved token - no prompt, no browser window:

```
/clammyh reloadah          ← uses saved token if valid, otherwise asks you to visit horizonxi.com
/clammyh reloadah token    ← forces file-only (never opens browser)
/clammyh reloadah local    ← re-reads the price JSON already on disk, no network at all
```

The token file is saved to:
```
%APPDATA%\HorizonXI-Launcher\HorizonXI\Game\config\addons\ClammyHorizon\data\horizon_bearer.txt
```

## Troubleshooting

| Symptom | Fix |
|---|---|
| Popup shows "No token yet" after visiting the site | Make sure you're **logged in** on horizonxi.com and navigate to an item page |
| Native host shows "not connected" | Re-run `install.bat`; confirm Node.js is in your PATH (`node --version` in PowerShell) |
| Token captured but `/clammyh reloadah` still opens a browser | Delete `horizon_bearer.txt` and let the extension re-capture, then try again |
| Extension icon missing after Chrome restart | Chrome unloaded an unpacked extension - go to `chrome://extensions` and click **Enable** |

## File layout

```
chrome-extension\
  manifest.json           Extension definition (Manifest V3)
  background.js           Service worker: receives token, calls native host
  content.js              Injected into horizonxi.com: intercepts fetch/XHR auth headers
  popup.html / popup.js   Toolbar icon popup - shows status, expiry, copy button
  icons\                  Extension icons (16/48/128 px)
  native-host\
    clammy_token_host.js  Node.js native messaging host (reads token, writes file)
    install.ps1           One-time setup: registry + bat wrapper
    install.bat           Double-click shortcut to run install.ps1
    -- generated by install.ps1, gitignored --
    clammy_token_host.bat  Path-specific launcher (your machine only)
    com.clammyhorizon.tokenhost.json  Chrome native messaging manifest (contains your extension ID)
```

---

## Privacy

The extension only intercepts requests to `api.horizonxi.com`. It never reads, modifies, or transmits data from any other site. The token is written only to the local file path shown above and is never sent anywhere else.
